# نظام إدارة الصيدلية المتكامل (Pharmacy Management System - El Ezaby)

مشروع جامعي متكامل وعالي الاحترافية لإدارة منظومة صيدليات ومستودعات، مبني وفقاً لأعلى معايير الويب والالتزام الدقيق بقاعدة بيانات SQL المرفقة (`El_Ezaby_Pharmacy_System`).

## 🚀 كيفية تشغيل المشروع

المشروع جاهز تماماً للتشغيل بأكثر من طريقة:

### الطريقة الأولى (الأسرع والمباشرة):
1. افتح المجلد على سطح المكتب: `Pharmacy-System`.
2. اضغط مرتين على ملف **`start.bat`** (أو افتح ملف **`login.html`** مباشرة في أي متصفح مثل Chrome أو Edge).
3. اضغط على أي من الحسابات التجريبية السريعة للدخول كمدير فرع أو صيدلي.

### الطريقة الثانية (عبر خادم Node.js المحلي):
1. افتح موجه الأوامر (CMD) أو PowerShell داخل المجلد.
2. اكتب الأمر:
   ```bash
   node server.js
   ```
3. افتح المتصفح على الرابط: `http://localhost:5000/login.html`.

## 🛡️ تفاصيل نقطة البيع المتقدمة (POS)
* **تحديد الفرع والموظف تلقائياً:** يتم جلبهما فوراً من بيانات تسجيل الدخول المخزنة في الجلسة.
* **إضافة الأدوية وترقيم البنود:** كل سطر يحتوي على `Item ID` متسلسل (1, 2, 3...) مع حساب لحظي للخصم والإجمالي.
* **آلية الأمان للـ Transaction:** فحص فوري للرصيد المتاح في `BRANCH_INVENTORY` قبل البيع لمنع بيع أي كمية تتجاوز الرصيد.
* **خصم المخزون الحقيقي:** يتم خصم الكمية المباعة فور حفظ الفاتورة وتحديث الأرصدة.
* **نقاط الولاء:** احتساب وإضافة نقاط للعميل في جدول `CUSTOMER` فورياً.
* **خدمة التوصيل المنزلي (Home Delivery):** عند تفعيل خيار التوصيل يظهر نموذج بيانات السائق، الرسوم، العنوان والتوقيع، ويتم حفظ الطلب فوراً في جدول `DELIVERY_ORDER`.
